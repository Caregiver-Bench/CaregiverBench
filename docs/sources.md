# Source library

Every rubric line should be traceable to one of the sources below. Titles and URLs were checked against the live page or DOI resolution on 2026-09-02; the **Used by** column lists the items that cite each source so a reviewer can validate citations in one pass. `scripts/export_review.py` writes the same information as a CSV.

When you add a source, add it here (keep the list alphabetical within each group) and cite it in the item's `sources` array. Prefer stable, publicly accessible documents; do not cite paywalled material as the sole basis for a `must_include` line.
