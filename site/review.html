    Who is reviewing?

    Your name is attached to every verdict and edit you export. Reviewers are credited in the item files and release notes unless you ask otherwise.

    How to review

    Read the question, then the rubric, then the reference answer. Edit any text directly; changes are highlighted and saved in this browser as you type. For each rubric line, choose a verdict. Check each source. Then give the item an overall verdict and press Export review when you're done with as many items as you want to send. Nothing you do here changes the dataset directly — the maintainer reviews every proposed change.

    Shortcuts: j/k next/previous item (when not typing).
